# Why the standard owns the protocol

The protocol was born inside the governor as *Protocolo de Empleados de La Generala*. Its shapes
were right; its ownership was not. An employee framework that is self-contained by design cannot
carry another framework's name in its manifest, and El Corresponsal said so by renaming its schema
to `corresponsal.employee-manifest/1.0.0` — at which point the governor's strict models would have
rejected it.

A protocol shared by many parties belongs to none of them. El Estatuto keeps the acronym with a
neutral reading — the Governed Employee Protocol — publishes every document under the `peg.`
namespace, renders the schemas from one source, and asks each framework to vendor them verbatim.
The gate compares bytes. The governor implements the protocol as a consumer; every employee
implements it as a provider; neither owns it.

The same reasoning moved the employee factory out of the governor: creating an employee must never
touch the governor's core, so the template that creates one lives with the standard that measures
it.
