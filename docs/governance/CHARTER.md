# Charter of El Estatuto

**Status:** in force since 2026-09-10.

## 1. The idea that governs

El Estatuto turns a house of independently built frameworks into one system: it fixes the form
every framework shares — repository, documentation, naming, tooling, verification, protocol — so
that a governor can connect any employee, an agent can continue any repository, and a new
employee can be created from zero already conforming. It owns the Governed Employee Protocol.

## 2. Responsibilities

| Responsibility | Its own result |
|---|---|
| R1. State the standard | `STANDARD.md` / `ESTATUTO.md`, clauses with identifiers |
| R2. Own the protocol | `peg.*` documents, rendered schemas, reference negotiation |
| R3. Measure conformance | `estatuto gate`, the result document, dated exceptions |
| R4. Create employees | `estatuto new-employee`, a repository conforming at birth |

## 3. Limits

- It governs form, never substance: what a framework *is* belongs to that framework's charter.
- It is not a runtime dependency of any framework; it is a tool their CI runs and a source of
  schemas they vendor.
- It claims nothing a control and a test do not enforce.

## 4. Character as a framework

The standard obeys itself: it declares its role, passes its own gate, renders its schemas from
one source, keeps its two editions in parity by machine, and changes only by decision and version.
