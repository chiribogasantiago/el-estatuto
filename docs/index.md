# El Estatuto

The framework standard of the house and the owner of the Governed Employee Protocol (PEG/1).

- Read [the standard](standard/STANDARD.md): what every framework — the governor and each
  employee — looks like, names, documents, verifies and speaks.
- Read the [protocol](protocol/PEG-1.md): how an employee is discovered, negotiated, assigned and
  attested.
- Follow [creating an employee](standard/NEW-EMPLOYEE.md) to start one from zero, and the
  [agent directive](standard/AGENT-DIRECTIVE.md) to continue one without breaking it.
- Run `estatuto gate <repository>` to measure any framework against the standard.

The owner's edition, in Spanish, is `ESTATUTO.md` at the repository root; both editions carry the
same clause identifiers and the gate verifies it.
