# Concepts

**Employee.** A framework with a craft. It receives typed assignments, works under explicit
authority and budget, and returns evidence-first proposals. It never accepts its own work.

**Governor.** The application that owns missions, grants, budgets and acceptance. Here, La
Generala. An employee never depends on the governor's code; it speaks the protocol.

**PEG/1.** The Governed Employee Protocol, owned by El Estatuto. A manifest declares what the
employee offers; a negotiation decides compatibility exactly; an assignment carries a context
capsule and conveys no authority; a result attests the assignment; a refusal is typed.

**Evidence first.** Every proposal rests on evidence with digests and references; cost equals the
sum of receipts; states are honest and name their cause.

**Invariants and policy.** The core keeps invariants only. Anything a deployment might want
differently is an injected policy with a named default.
