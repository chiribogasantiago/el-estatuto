# 0001 — __NAME__ is built under El Estatuto

**Status:** accepted __DATE__.

## Context

Frameworks in this house are created and continued by different people and agents. Without a
shared standard each one drifts in repository shape, documentation, naming and protocol, and the
governor cannot connect them uniformly.

## Decision

__NAME__ conforms to El Estatuto __STANDARD_VERSION__: its repository shape, documentation,
naming, tooling, verification chain and the Governed Employee Protocol are the standard's, and
`estatuto gate .` measures it in CI. Deviations are recorded as dated exceptions backed by a
decision, never as silent drift.

## Consequences

One convention to learn. The governor connects this employee like any other. Structure changes
happen in the standard first.
